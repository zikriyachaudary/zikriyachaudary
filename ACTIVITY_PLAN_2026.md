# 2026 Weekly Contribution Plan (Real Work, Natural Pattern)

Goal: Keep a natural-looking activity pattern with some quiet weeks and some high-output weeks.

## Intensity Levels
- L0 (Off): 0 commits
- L1 (Light): 1-2 commits in the week
- L2 (Normal): 3-5 commits in the week
- L3 (High): 8-12 commits in the week

## Monthly Rhythm (repeat each month)
- Week 1: L2
- Week 2: L3
- Week 3: L1
- Week 4: L0 or L2 (alternate each month)
- Week 5 (if exists): L1

## Quarterly Focus
- Q1 (Jan-Mar): Foundation
  - README improvements
  - Add/update project documentation
  - Small utility scripts
- Q2 (Apr-Jun): Build
  - Ship small features
  - Refactor old code
  - Add tests for touched code
- Q3 (Jul-Sep): Learn + Apply
  - Build 1-2 mini projects
  - Try one new tool/library each month
- Q4 (Oct-Dec): Polish + Showcase
  - Improve existing repos
  - Bug fixes and cleanups
  - Pin best projects on profile

## Weekly Task Menu (pick real tasks)
- Update one section in README with meaningful changes
- Add a small script/tool used in day-to-day work
- Fix one issue in any active repo
- Add tests for one existing module
- Improve docs for setup or usage
- Refactor one small component/function

## Example 8-Week Pattern (Natural Blocks)
- Week A: L3
- Week B: L1
- Week C: L0
- Week D: L2
- Week E: L3
- Week F: L2
- Week G: L0
- Week H: L1

## Rules To Keep It Legit
- Every commit should correspond to actual useful work.
- Use clear commit messages describing real changes.
- Prefer fewer meaningful commits over many tiny noise commits.
- Keep commit email linked to your GitHub account.
